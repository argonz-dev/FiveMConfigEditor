# 🚀 Quick Start - AI Chat Assistant

## Langkah Cepat Menggunakan AI Assistant

### 1️⃣ Buka Aplikasi
```
Jalankan: FiveMConfigEditorWPF.exe
```

### 2️⃣ Akses AI Chat
- Klik tombol **🤖 AI Chat** di sidebar kiri
- AI Assistant akan langsung siap digunakan (sudah terkonfigurasi)

### 3️⃣ Mulai Bertanya!

#### Contoh Pertanyaan:

**Optimasi Hardware Spesifik:**
```
"Saya punya RTX 3060 Ti dan Ryzen 5 5600X. 
Apa setting optimal untuk 1080p 60 FPS di FiveM?"
```

**Troubleshooting:**
```
"FPS saya turun drastis saat di kota. 
Bagaimana cara mengatasinya?"
```

**Penjelasan Setting:**
```
"Apa perbedaan antara MSAA dan FXAA? 
Mana yang lebih baik untuk performa?"
```

**Analisis Config:**
```
1. Load file CitizenFX.ini Anda
2. Klik tombol "📊 Analyze Config"
3. AI akan menganalisis dan memberikan rekomendasi
```

### 4️⃣ Quick Actions

Gunakan tombol shortcut untuk pertanyaan umum:

- **💡 Optimization Tips** - Tips optimasi umum GTA V
- **🎮 Best Settings for RTX** - Rekomendasi untuk GPU RTX series
- **🔧 Fix Low FPS** - Solusi masalah FPS rendah

### 5️⃣ Tips Penggunaan

✅ **DO:**
- Sebutkan spesifikasi hardware Anda untuk rekomendasi akurat
- Jelaskan masalah dengan detail
- Gunakan "Analyze Config" untuk insight spesifik
- Tanya follow-up questions untuk klarifikasi

❌ **DON'T:**
- Jangan tanya hal yang tidak berhubungan dengan GTA V/FiveM
- Jangan spam pertanyaan yang sama berulang kali

### 🔧 Troubleshooting

**Q: AI tidak merespons?**
- Pastikan koneksi internet aktif
- Cek apakah API service berjalan di `localhost:1430`
- Restart aplikasi

**Q: Response terlalu lambat?**
- Normal untuk pertanyaan kompleks (10-30 detik)
- Cek koneksi internet Anda

**Q: Ingin clear chat history?**
- Klik tombol **🗑️** di pojok kanan atas

### 💡 Pro Tips

1. **Spesifik = Better Results**
   ```
   ❌ "Setting terbaik?"
   ✅ "Setting terbaik untuk RTX 3070 di 1440p targeting 60 FPS?"
   ```

2. **Gunakan Analyze Config**
   - Lebih akurat karena AI melihat config aktual Anda
   - Rekomendasi spesifik untuk setup Anda

3. **Follow-up Questions**
   - AI ingat konteks percakapan
   - Bisa tanya detail lebih lanjut

4. **Kombinasi dengan Preset**
   - Tanya AI untuk rekomendasi
   - Apply manual di tab Config
   - Save sebagai preset
