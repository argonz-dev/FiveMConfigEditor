# FiveM Config Editor v1.0.0

## 🎉 Initial Release

### Features
- ✅ CitizenFX.ini configuration editor
- ✅ Graphics settings management
- ✅ Preset system (save/load configurations)
- ✅ Snapshot history with auto-detection
- ✅ Mod manager
- ✅ AI Assistant for optimization tips
- ✅ Auto-update functionality
- ✅ Dark theme UI

### Installation
1. Download `FiveMConfigEditorWPF.exe`
2. Run the executable
3. Select your FiveM installation folder on first run

### Requirements
- Windows 10/11
- .NET 8.0 Runtime (included in self-contained build)
- FiveM installed

### Auto Update
The application will automatically check for updates on startup and notify you when a new version is available.
